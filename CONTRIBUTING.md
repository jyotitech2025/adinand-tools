# Contributing

Issues and pull requests about the tools in this repository are welcome — a wrong result, a file a tool cannot read, a browser it fails in.

The website copy of each tool is the source of truth, so an accepted fix is made there first and mirrored here.

For help with an app itself — your account, a purchase, a bug inside the app — please write to the app's support address instead; GitHub issues are not monitored for app support:

- DocFind — support@docfindapp.com
- Adinand Email Cleaner — support@adinandemail.com
- SubSense — support@subsenseapp.com
- Adinand Auto File Sorter — support@adinandsorter.com
